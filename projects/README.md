# Projects

One home per builder, one directory per project: `projects/<handle>/<project>/` with `README.md`,
`meta.json` and `index.html` or `<name>.om` (plus optional `.js`, `.css`, `.md`, `.txt`, `.patch`).
Saves land on `u/<handle>`; published projects arrive as pull requests from `p/<handle>/<project>`
via Allen at https://www.aienos.com/allen/ and go live only after Drake reviews and merges them.

No projects are live yet.
